# 张一鸣微博档案（非官方复原）

把公开流传的《张一鸣微博日记 2286 条》整理本还原为一个可搜索、可按年份浏览的旧微博风格静态网站。

## 当前数据

- 高置信度解析：2164 条（坐标重建版，较旧解析多恢复 4 条）
- 时间：2010-04-29 ～ 2016-03-25
- 数据来源：公开流传 PDF 文本层
- 原始整理本：方建勇，2019-05-25
- 不伪造：原微博 ID、互动数、图片、视频、未保存的转发关系

网上同时流传名为“张一鸣微博2886条.pdf”的文件，但其文档内标题写的是“2286条”。本站不为了凑数把转发正文里其他人的时间头算作张一鸣自己的微博。

## 本地运行

python3 -m http.server 4173

然后打开 http://127.0.0.1:4173/ 。

## 重新生成数据

本地 data/source/ 下的 PDF 和提取文本不提交到 Git。解析流程见 scripts/parse_archive.py。

## 数据修复说明

当前解析器不再直接拼接 PDF 字符串，而是依据每个字形的 x/y 坐标重建行内空格，再在页级别移除第三方页脚。这样可以保留英文词间距，也不会再把 6岁的时候 的 6 误当页码删除。
